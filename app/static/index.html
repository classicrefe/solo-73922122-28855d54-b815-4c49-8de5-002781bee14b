防火墙规则变更差分台（IPv4 / TCP，首条匹配，默认拒绝）

粘贴旧、新两份有序 JSON 规则（各 ≤ 20 条），系统用边界切分精确枚举整个流量空间，输出全部且互不重叠的新增放行 / 新增阻断区域，不做抽样。

旧规则集（变更前）

新规则集（变更后）

规则格式：数组，每条规则为对象，字段 id（整数或非空字符串，同一份内唯一）、 source 与 destination（严格 IPv4 CIDR，主机位须为 0，如 10.0.0.0/24，全网用 0.0.0.0/0，单机用 /32）、 portRange（目的端口闭区间 [下界, 上界]，0-65535 整数）、 action（小写 allow 或 deny）。匹配按数组顺序，首条命中生效；全部未命中即默认拒绝。 
[
  {
    "id": 1,
    "source": "10.0.0.0/8",
    "destination": "172.16.0.0/12",
    "portRange": [80, 443],
    "action": "allow"
  }
]
